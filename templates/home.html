FloodSense: Flood Prediction System

Machine Learning for Disaster Preparedness

About This Project

Floods are among the most devastating natural disasters, causing loss of life, property damage, and displacement of communities worldwide. Early prediction of flood risk using historical weather and rainfall data can help authorities and citizens take timely preventive measures.

FloodSense is a machine learning-based flood prediction system that analyzes parameters such as temperature, humidity, cloud cover, and seasonal rainfall patterns to classify whether a region is at risk of flooding.

Built as part of the SmartBridge internship program, this system trains multiple classification models, compares their performance, and deploys the best model through an interactive web application.

Key Features

  • Historical rainfall and weather data analysis
  • Multiple ML models: Decision Tree, Random Forest, KNN, XGBoost
  • Automated model selection based on accuracy
  • Interactive web-based flood risk prediction
